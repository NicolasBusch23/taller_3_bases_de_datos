- Entorno Virtual: Mini computadores dentro de mi computador, el cual, tendrá todas las dependencias o librerías instaladas
Permite portabilidad y reproducibilidad

Para crear un entorno virtual: python -m venv [nombre_entorno]
Para activar el entorno virtual: [nombre_entorno]\Scripts\activate
--- Observar cambio de presentación en Terminal
Para desactivar del entorno virtual: > deactivate

- Comandos de interés:
> pip list: Lista las librerias instaladas
> pip freeze > requirements.txt: Copia al archivo .txt las librerías que tengo instaladas en mi entorno virtual
> pip install -r requirements.txt: Porfavor instale de manera recursiva las librerias que aparecen en requirements

> git init: Le digo a la máquina: Voy a trabajar con git y empezaré a hacer commits
> git add . : Hagame seguimiento de todos mis archivos
> got status: Identificar el estado en el que se encuentran loa archivos:
U: Untracked
M: Modified
A: Añadidos al Staged
> git commit

> git log --oneline: Para ver los commits que he hecho
